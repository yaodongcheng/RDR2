# 荒野大镖客 2 · 任务执行逻辑还原（目标层 / 失败条件）

> 回答："每个任务的具体执行逻辑也有了吗？"
>
> **脚本层没有，目标层有了。** `script_rel.rpf` 已从 `update_2.rpf` 抽出，但它用 RPF8 tag `0xC6(198)` 加密，密钥不在现有表里，`rdr2rpf list` 直接报 `Can't get encoder key!`。所以"触发器 / 生成 / 分支 / 奖励"仍然拿不到；本文件给的是**能从游戏资源里确证的另一半**：每条任务的玩家目标、失败条件、挑战与对白量。

## 0. 为什么拿不到 `.ysc`（实测证据）

| 项 | 实测结果 |
|---|---|
| 脚本包位置 | `update_2.rpf → x64/levels/rdr3/script/script_rel.rpf`，113,038,110 B |
| 已抽出 | ✅ `work/script_probe/x64/levels/rdr3/script/script_rel.rpf` |
| 包头 | `8FPR`(RPF8) / version 1639 / entries 27470 / **tag 0x00C6** / platform 121 |
| 解密 | ❌ `Can't get encoder key!`（`Cipher.GetCipher`，密钥表只有 0–162 + 192） |
| 其他副本 | 全盘 RPF 搜 `.ysc` 0 命中；`parseddata.rpf` 615 个 ymt 全部 signature-protected |

> 换句话说：**不是没找到文件，是找到了但解不开**。需要 CodeX 的脚本反编译器，或补 tag 198 的 AES key。

## 1. 现在我们能给出的四层

| 层 | 来源 | 覆盖 | 能回答 | 不能回答 |
|---|---|---|---|---|
| 定义层 | `missions.meta` | 270/270 | 有哪些任务、属于哪章、过场包是谁 | 任务内部怎么跑 |
| **目标层** | 各任务 `<id>.yldb` | 105 个任务 / 637 条目标 | 玩家被要求做什么、做到哪一步 | 目标之间的触发条件与顺序 |
| **失败层** | 同上 | 443 条失败条件 | 什么情况会失败（跟丢、离场、NPC 死亡、被惊动） | 判定表达式与阈值 |
| 挑战层 | `challenges_sp_missions.meta` | 105 条主线 / 308 条 | 金牌条件（时间、爆头、精准度、不受伤） | — |
| 台词层 | 任务音频库 `.yldb` | 128 任务 / 41,005 行 | 任务里说了什么 | 谁在什么条件下说 |

这四层足以还原"**一关的流程骨架**"：进场 → 目标 A/B/C → 失败条件 → 结算挑战；但还原不了"**脚本怎么实现**"：哪个 volume 触发哪个目标、生成几个 ped、什么条件下切分支。

## 4. 仍然缺的部分与可行路线

> 2026-10-19 追加：脚本层已用 build 1355 反编译库补上（105/105 主线、1054 条脚本目标），
> 见 **`RDR2_脚本级任务解析.md`**。本地字节码仍因 AES key #198 解不开。

| 缺什么 | 影响 | 可行路线 |
|---|---|---|
| 触发器 / 区域判定 | 不知道目标在什么位置、什么条件下推进 | CodeX 反编译 `.ysc`；或补 AES key `0xC6` |
| 生成表（ped/载具/道具） | 不知道一关刷多少人、什么模型 | 同上；`metapeds.ymt` 另需 PSIN schema |
| 分支与失败表达式 | 不知道"如果…则…" | 同上 |
| 奖励与结算 | 不知道给多少钱/物品 | 同上；部分可从 `goals`/经济表反推 |

> 结论：**"每个任务做什么"已经有了；"每个任务怎么被脚本驱动"还没有。**前者足够写攻略、做关卡复刻、排配音与过场；后者要动脚本层。
