# 说话人采样清单（录制用）

> 目的：用**最短的时间**验证"录音 → 自动切句 → 查看器逐句播放 → 标注说话人"这条链路。
> 每条都是 5~15 句的小对话，录 1~2 分钟就够。
> **只需要声音**（OBS/Xbox 录屏都行），不需要截图。

---

## 怎么录

1. 双击根目录 `开始录音分析.bat`（它会盯着 `raw/capture/`）
2. 进游戏，走到下面任意一段对话前
3. 按 `Win + Alt + R` 开始录 → 让对话**完整说完** → 再按一次停止
4. 把 mp4 拖进 `raw/capture/`，等脚本处理完，打开查看器听

> 关键：**一段话一个文件**，两段之间停 1 秒以上再开始录下一段。

---

## 推荐先录这 5 段（从易到难）

### 1. `WNT1_BANT` — 6 句（第一章 · 和迈卡对话）

- 触发：WNT1「西部亡命之徒」开局，跟着迈卡走，靠近他时自动触发
- 出场：亚瑟、迈卡
- 台词预览：

```
1  我很高兴你没事，迈卡。
2  当然。
3  问他是否见过约翰。
4  暴风雪来临之后，就什么也没有看见了。
5  他没见过他。
6  我希望......麦克和西恩也还活着。
```

> 这段最好认：只有两个人，且第 3 句是**玩家选项**（"问他…"），可以直接验证我们的切句对不对。

### 2. `WNT1_TALK2` — 8 句（第一章 · 骑马下山时）

- 出场：达奇、亚瑟（比尔等人在旁边）
- 预览：`不敢相信，我们还失去了戴维。` / `他是最后一个，亚瑟。…`
- 难点：这段会提到"戴维"，我们的自动推断会被带偏——正好用来验证"人工标注"是否必要。

### 3. `WNT1_INT_WAGON` — 14 句（第一章 · 马车里的过场）

- 出场：达奇、亚瑟、何西阿、艾比盖尔（画外）
- 预览：`艾比盖尔说他快不行了，达奇。` / `我们得找个地方歇脚。`
- 价值：多人群聊，能测"3 人以上"的标注效率。

### 4. `DST1_CHOICE` — 短对话（第二章 · 老朋友们，审问时）

- 出场：亚瑟、达奇、奥德里斯科帮俘虏
- 价值：含玩家选项分支，能测"选项行 vs 台词行"的区分。

### 5. `WNT1_INT_CABIN` — 64 句（第一章 · 木屋过场）

- 出场：全帮派（十几人）
- 价值：**压测**——最长的一段，用来评估"标完一整场要多久"。
- 建议最后再录。

## 录完之后我会做什么

```bash
# 自动：切句 + 认对话组 + 写 export/story/audio/<组>_<n>.wav + 重建查看器
开始录音分析.bat
```

1. 打开 `export/story/index.html?id=WNT1` → 剧本页对应台词旁出现播放器；
2. 打开 `export/story/annotate.html` → 边听边点说话人（每段有「全设 XX」按钮）；
3. 导出 `speaker_overrides.json` → 放回 `export/story/` → 重建 → 逐句显示"谁说的"。

---

## 如果实在不想录音

直接开 `export/story/annotate.html` 人工标也行，只是没有声音辅助、会慢一些。
两种方式的产物是同一个文件（`speaker_overrides.json`），可以混用。
