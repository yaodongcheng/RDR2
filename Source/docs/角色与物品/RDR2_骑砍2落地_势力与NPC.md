## 0. 四个问题，先给结论

### ① 3000×3000 是上限，不是标准——我上一版的说法要改

上一版写「建议把 3000 降到 1600」，措辞像是在否定 3000。正确理解应该是：

> **3000 是预算天花板，不是每个城市都要做到 3000。**

RDR2 的圣丹尼斯实测 **862×955 m**，放进 3000 的预算里只用了 **30%**——它是合格的，不需要为了"填满 3000"去硬扩。实际做场景时按内容量定尺寸：

| 档位 | 你说的上限 | RDR2 实测 | 建议实际使用 | 说明 |
|---|---|---|---|---|
| 大城市 | **3000×3000（上限）** | 907（圣丹尼斯） | **900~1200**；含港区 1600 | 3000 只留给"首都+多城区"或后续扩展 |
| 城堡 | **1200（上限）** | 115~526 | **500~800** | 庄园 500 主体 + 外院；要塞只当内堡 |
| 村庄 | **1000（400~1800）** | 80~526 | **400~600 中心镇 / 150~300 小村** | 1800 的上限基本用不到 |
| 藏身处 | **800（300~1400）** | 93~315 | **300~500** | 其余是包围它的林地/山谷/水网 |
| 野战 | **2000×2000（上限）** | — | **1200~2000** | 上限留给大规模会战 |

> 一句话：**按上限做 = 每个村都留 3 倍空地**。正确做法是按内容量定场景，上限只用于压力测试和后续扩展。

## 1. 为什么这样分层（骑砍2 的判定标准）

| 类型 | 骑砍2 里的判定 | RDR2 对应 |
|---|---|---|
| **Town 城市** | 有市场、商店、银行、酒馆、监狱，能收税、能驻军 | 9 座有商店的城镇 + 瓜玛的阿瓜多切斯 |
| **Castle 城堡** | 有围墙、驻军、领主宅邸，能独立防守，但不一定有市场 | 两座庄园、两座军堡、监狱岛、加固牧场、围墙工厂、部落围栏 |
| **Village 村庄** | 只有产出（粮/马/矿/鱼），**必须依附**城或堡 | 牧场、农场、矿村、沼泽渔村、车站、种植园 |
| **Camp 营地** | 玩家/帮派营地，不参与经济 | 范德林德帮 4 个章节营地 |
| **POI 野外点位** | 独屋/驿站/小营地，不参与经济，也不需要依附 | 草皮屋、朗尼棚屋、岔路酒馆、双子岩 |
| **Hideout 藏身处** | 匪帮巢穴，不参与经济，可被清剿 | 迈卡藏身处、豁牙裂口 |

### 1.1 为什么这些是 Castle 而不是 Town

| 城堡 | 理由 |
|---|---|
| 布雷斯韦特庄园 / 卡利加种植园 | 围墙 + 主宅 + 庭院 + 马厩 + 田庄，但没有市场；典型的"庄园城堡" |
| 华莱士堡 / 布商堡 | 纯军事要塞，围墙 + 门楼 + 操场 + 兵营 |
| 西西卡监狱 | 河心岛，只能坐船进，天然城堡 |
| 垂犬牧场 | 加固牧场，奥德里斯科尔据点，围墙 + 牲口栏 |
| 康沃尔煤焦油厂 | 围墙 + 烟囱 + 工人宿舍，工业城堡 |
| 瓦匹缇 | 部落围栏营地，按"部落城堡"处理 |

## 3. 势力体系

### 3.0 我是按什么分配的（四条依据）

| 依据 | 说明 | 例子 |
|---|---|---|
| **地理** | 据点落在哪个州/地区，优先归该地区的实际控制者 | 安尼斯堡在罗诺克山脊 → 康沃尔矿业带 |
| **游戏内实际控制** | 谁驻军、谁收税、谁有警长/法官 | 华莱士堡驻联邦军 → 联邦；布商堡被德尔·洛博占据 → 匪帮 |
| **剧情** | 任务里谁在这里活动、谁跟这里有仇/合作 | 布雷斯韦特庄园 → 布莱斯韦特家族；罗兹 → 格雷家族 |
| **经济** | 矿、牧场、种植园、码头归谁 | 康沃尔煤焦油厂 → 康沃尔公司；奥兰治种植园 → 布莱斯韦特 |

**五个例外**（不能只看地理）：

- **圣丹尼斯**：名义上是市政府，实际是**勃朗特黑帮**控制地下；归 LEM，但领主写勃朗特。
- **罗兹**：格雷与布莱斯韦特**争夺中**；归 LEM，领主写格雷，但备注"两家争夺中"。
- **范霍恩**：无警长、无银行，**没有势力真正控制**；单列为 FREE。
- **布商堡 / 垂犬牧场**：法理上属于联邦/牧场主，**实际被匪帮占据**；按"实际控制"归 OUT。
- **范德林德帮**：**只有营地、没有领地**；营地不参与经济，不算村庄。

## 9. 一句话总结

> **3000 是上限，不是标准**；圣丹尼斯 907 m 完全够用，别为了填满预算硬扩。
> **12 个村庄全部有主**，最远 1291 m（叙事确认）、最近 343 m；3 个远郊牧场升城堡、4 个独屋改点位。
> **8 个势力**里联邦是"帝国位"（17/43），要平衡就拆出"西部自由镇"。
> **NPC 模型 408 个全在、85 个有名字、142 个进了名册**；
> 店主/医生/警长另外找到 **53 个城镇专属语音库**，但都**没有个人姓名**；
> "平时在哪个城"不是解包字段——`metapeds.ymt` 和 `script_rel.rpf` 解了才算彻底。
