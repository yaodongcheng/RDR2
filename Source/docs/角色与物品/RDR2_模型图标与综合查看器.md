## 2. 图标：RDR2 没有 2D 图标，但可以一键导出

RDR2 的背包/商人物品展示用的是**3D 模型转台**，不是 2D sprite。
`ui_itemviewer.rpf`（105 个 `.ytd`）里只有小册子/信件/技能页，`item_textures.rpf` 里是服装/广告/UI 头图，**没有"每个道具一张图标"的图集**。

所以查看器里加了两个按钮：

| 按钮 | 作用 |
|---|---|
| **导出截图 PNG** | 当前画布原样截图 |
| **导出图标（透明 512）** | 隐藏网格/背景，渲染 512×512 透明 PNG，直接当背包图标用 |

> 想批量出图标，可以对 `export/viewer/models/*/*.gltf` 跑一遍 headless Chrome/Blender 渲染；
> 单个模型现在可以在页面里点一下导出。

```

→ 起本地服务 http://127.0.0.1:8788/viewer/index.html
```

（必须走 http，不能直接双击 index.html；ES module + fetch 在 file:// 下会被拦。）

| 左侧 | 4 个标签：**武器 / 道具 / 任务 / 对白** + 搜索框 + 分类列表 |

### 3.3b 中文名

| 类型 | 处理 |
|---|---|
| 武器 | 按 `w_*` base 映射到官方中文名（牛仔左轮、斯科菲尔德、栓动步枪、滚轮闭锁式步枪…）；**配件（grip/sight/clip/wrap）已隐藏**，变体合并 |
| 道具 | 词根字典 + 人工表：短吻鳄牙齿、培根卷心菜、炖牛肉、箭束、火药、燃烧瓶…；没命中的显示「中文类别 · 内部名」 |
| 任务/对白 | 任务 ID + 中文章节名；对白已是纯中文 |

> 道具的**精确**官方名需要 yldb 的 key→string 表；目前 key 表只对部分武器 key 生效，
> 所以道具是“常见项精确 + 其余按类别+内部名”的折中。

## 3.4 贴图与已知限制

**已修：**

- **道具贴图**：`TexLib` 从道具 YTD 里解出 albedo，**446 张贴图**已写进 glTF；查看器里 `p_alligator_tooth01x`、`p_bacon_cabbage01x` 等已经能看到真实颜色。
- **对白乱码**：只保留含中文的行，过滤掉 yldb 里被误当台词的二进制串；**99,532 → 49,290 条中文**，GUA1 现在只剩正常对白。

**还没完全解决：**

1. **武器没有单张 albedo**：RDR2 武器走 `standard_weapon_2lyr`，用 `w_blank_ab` + `_pal`（调色板）+ `_eg`（tint 遮罩），颜色来自调色板而不是 albedo。
   查看器目前**按类别着色**（步枪棕色、左轮深灰、霰弹枪木色…），不是逐把精确的调色板颜色。
   要精确还原，需要实现 RDR2 的 palette/tint shader。
2. **多部件武器可能"散开"**：简化导出没有保留每个子部件的节点变换，步枪的枪托/枪管/瞄准镜可能分离显示。
3. **`.yft` fragment 未转**：875 个 fragment 道具还没进查看器。
4. **部分道具贴图缺失**：1,196 个模型里 446 个拿到 albedo，其余是共享贴图/未抽到的 YTD。
5. 任务页的目标/挑战是**全局 261 条**，没有逐任务绑定。

## 4. 对白归属：129 个任务已对上，173 个是活动

### 4.1 已对上 `missions.meta`

| 类型 | 音频库 | 说明 |
|---|---|---|
| 主线 | **94 / 105** | 第 1~6 章 + 尾声 |
| 支线/赏金 | **33 / 121** | 随机事件、随机剧情、赏金 |
| 其他 | 2 | 少数跨类 |
| **合计** | **129** | |

每个任务的对白在 `export/story/mission_dialogue/<MISSION_ID>.txt`，
索引在 `export/levels/world/mission_dialogue_index.csv`。

### 4.2 剩下 173 个音频库是什么

| 类型 | 数量 | 例子 |
|---|---|---|
| 同伴活动 | **64** | `cab2`、`cbl1`、`cch*`、`cdt*`…（`c*` 前缀） |
| 同伴（Abigail） | 2 | `abi5`、`abi6` |
| 赏金 | 2 | `bch3`、`bcon` |
| 随机/抢劫 | 11 | `rcmp`、`rehc`…（`r*` 前缀） |
| 其他活动（代码不对应 missions.meta） | **94** | `len*`（Lenny）、`kie*`（Kieran）、`hnt*`（狩猎）、`fish`、`phm*`、`sp*`、`sr*`、`sc*`… |

> 对白已做清洗：只保留含中文的行，去掉 yldb 里被误当台词的二进制可打印串；
> 原始 99,532 行 → **49,290 条中文台词**。GUA1 现在只剩正常对白。

> 这 173 个**不是主线/支线任务**，而是**同伴活动、赏金、随机事件、狩猎/钓鱼/小游戏**的音频库。
> 它们的对白全文已导出到 `export/story/mission_dialogue/_unmatched/`，只是没有对应的 `missions.meta` 任务 ID。

### 4.3 还能不能继续精确？

能，但需要额外数据：

- 同伴活动：需要 `companion` 活动定义（哪个 code 对应哪个角色/活动）；
- 赏金：需要赏金合同表（`RBT*` 与 `bch/bcon` 的对应）；
- 其他活动：需要脚本/活动表（`.ysc` 或 `activities.meta`）。

现在能确定的粒度是：**任务音频库（129）→ 任务 ID**；**活动音频库（173）→ 活动类型**。
再往下"这句是谁说的/哪个步骤"仍然需要 `.ysc` + 音频时间轴。
