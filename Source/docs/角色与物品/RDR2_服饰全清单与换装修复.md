## 1. 服饰从哪来（数据源）

RDR2 的人物是**槽位拼装**：头 / 头发 / 胡须 / 上衣 / 马甲 / 外套 / 裤子 / 靴子 / 帽子 / 领巾 / 腰带 / 枪套 / 手套…
每个槽位下有很多件 `xxx_mr1_012.ydd`（`m`=男 / `f`=女，`r1`=rank）。玩家在衣柜里换的就是这些件。

| 来源 | 路径 | 件数 | 用途 |
|---|---|---|---|
| **通用部件** | `raw/npc/models/generic/*.ydd` | **3 590** | 玩家/路人换装库，男女都有（男 2032 / 女 1041） |
| **主角专属** | `raw/npc/models/player/*.ydd` | **1 360** | 亚瑟 `player_zero_*`、约翰 `player_three_*` 的专属服装 |
| **剧情角色专属** | `raw/npc/models/cutscene/*.ydd` | **1 156** | `cs_<名字>_<件名>_<编号>.ydd` + `merge_N.ydd`（整套合并件） |

> 命名规则：`<槽位>_<性别><rank>_<编号>[_<变体>].ydd`，例如
> `coat_mr1_012.ydd` = 男装外套第 12 号；`boot_fr1_045_calf.ydd` = 女靴 45 号的小腿变体。
> 剧情角色是 `cs_dutch_ms1_coat_003.ydd` = 达奇的 3 号外套。

## 3. 剧情角色为什么穿得奇怪（根因）

### 3.1 `merge_N.ydd` = 一整套 outfit，不是"部件分组"

以达奇为例（`cs_dutch_ms1_merge_*.ydd` 实际内容）：

| 文件 | 里面是什么 | 顶点 |
|---|---|---|
| `merge_17` | 双外套（Coat_001 + Coat_006）+ 靴 + 靴套 + 手套 + 枪套 + 衬衫 + 裤 | 35 653 |
| `merge_18` | 头 + 马甲 + 领带 + 外套 + 靴 + 手套 + 胸花 + 裤 | 15 196 |
| **`merge_22`** | **头 + 眼 + 牙 + 眉 + 头发 + 胡须（只有脑袋）** | 16 342 |
| `merge_26` | 衬衫 + **裸上身** + 外套 | 9 661 |
| `merge_27` | 头 + **裸上身** + 背带 | 6 568 |

旧逻辑：`身体 = 顶点最多的那组` → **merge_17（35 653）**，再看"有没有头"→ 没有 → 补 `merge_22`。
结果：**双外套叠穿 + 没有下半身/靴子错位**，这就是"衣服很奇怪"。

更糟的是 `Head_000` 这个名字会骗人：`merge_18` 里叫 `CS_Dutch_MS1_Head_000` 的 drawable，
实际是**上半身皮肤**（包围盒 1.2 m 宽 × 0.55 m 高），按名字判会以为"已经有头了"，于是**不补真头 → 没脑袋**。

### 3.2 修复规则（`tools/rdr2_npc_export.py`）

| # | 规则 | 实现 |
|---|---|---|
| 1 | **按槽位覆盖打分**，不按顶点数 | 上装 +3、下装 +3、鞋 +2、头 +1、发型/配饰各 +0.5；纯裸体 −10 |
| 2 | **同套重复件扣分** | 双外套 / 双靴各 −1.2（那是叠穿，不是"更完整"） |
| 3 | **头部用几何判定，不信贴图名** | 包围盒最长边 <0.42 m、高 <0.42 m、中心高于 1.40 m 才算"头" |
| 4 | **永远从"真正的头部组"补头** | 选 `head_n`（几何头数量）最多的 merge 组，和身体组合并 |
| 5 | **帽子贴头** | 帽子顶点相对头骨挂点存放，静态导出会浮空；按"发顶下 3 cm"下压 |
| 6 | **兜底补件** | 下装/靴/上装/头发常常是独立 `.ydd`（不在任何 merge 里），缺了按槽位补最大的一件 |

## 4. 贴图修补（2026-10-22 补）

- 6106 件里 **5 512 件（90.3%）有真实贴图**；594 件因为包里没有同名条目，改用**部位兜底色**（不再白模）；
- 回退链：`原图 → 998→999 → 同 c 换 999 → 换 c → 换 c+999`，共救回 374 个部件；

## 5. 已知限制（诚实清单）

| # | 限制 | 影响 | 后续 |
|---|---|---|---|
| 1 | **`metapeds.ymt` 的 PSIN 格式没解** | 拿不到"游戏官方认定的默认 outfit 是哪一套"，只能按完整度选；同一个角色可能有 2~3 套都合理（冬装/正装） | 需要按 RAGE PSIN 结构写解析器；解了就能精确还原"第几章穿哪套" |
| 2 | **部分女性部件只有 `.yld`** | 莎迪的头发、部分披肩/睡裙仍缺（`.yld` 的 drawable 指针布局与 `.ydd` 不同） | 按 CodeWalker 的 yld 定义补解析 |
| 3 | **帽子/头发是相对骨骼挂点存的** | 已用"贴头"规则压下去，但不同帽型仍可能有 1~3 cm 偏差 | 有骨骼后按 socket 精确挂 |
| 4 | **部分贴图是 tint 遮罩**（已缓解） | 真色在 `assets_tints.ymt` 调色板里。现在会自动识别"高饱和 + 色相散乱"的遮罩并降饱和成中性布色（夏洛蒂的彩虹衬衫就是这么修的），但**拿不到原本的蓝/红/绿** | 解 `assets_tints.ymt` 还原真实配色 |
| 5 | ~~只有 2D 缩略图~~ **已补 3D** | 6106 件全部导出 `.glb`（4.17 GB，288 秒），`viewer/clothing3d.html` 可直接转着看；缩略图保留用于列表快速浏览 | — |
