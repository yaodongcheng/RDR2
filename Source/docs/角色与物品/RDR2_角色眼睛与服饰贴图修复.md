# 角色眼睛（眼球/瞳孔）与服饰贴图修复

> 两个问题一起修：
> **① 导出的角色眼眶是空的，看不到眼球和瞳孔；② 部分服饰没有贴图，渲染成白模。**
> 结论：都不是"没解出来"，而是**贴图的用法错了**——眼睛拿到的是 tint 遮罩、眼罩层被导成不透明、
> 服饰的贴图名在包里对不上（差一个变体号）。三处都补了兜底。

---

## 1. 眼睛：为什么是空的

### 1.1 两个叠加的原因

| # | 原因 | 证据 |
|---|---|---|
| 1 | **眼球贴图是 tint 遮罩，不是画好的眼球** | `eyes_gen_0000_c0_999_ab` 三个通道分别代表 **R=虹膜盘 / G=眼白 / B=瞳孔**；直接当颜色用是荧光绿，被"降饱和"处理后又变成一颗**灰球**——看起来就像没有眼球 |
| 2 | **`eye_cap` 罩层被导成了不透明** | `Eye_Cap_Gen_0000_c0_000_ab` 是一层纯色 (104,46,40) 的"湿润高光罩"，位置在眼球**前面**（z 0.097~0.106 > 眼球 0.087~0.105），不透明就把眼球挡住了 |

另外还有**四个连带问题**，修眼睛时必须一起处理，否则看起来仍然"没有眼睛"：

| # | 问题 | 现象 | 修法 |
|---|---|---|---|
| 3 | **按贴图名去重，把真头丢了** | 同一张贴图下挂多个部件（头 + 鼻/耳），`Head_000` 被去重成 5 cm 的小块 → 杰克成了"大头娃娃/大眼球" | 去重键改成 `(贴图名, drawable hash)` |
| 4 | **儿童眼球按成人尺寸做** | 杰克的眼睛有成人大小、外凸 | 按身体高度等比缩放（基准 1.9 m） |
| 5 | **头/眼在"不带性别后缀"的变体里** | `cs_josiahtrelawny_m_merge.ydd` 才有特里劳尼的头+眼，只扫 `..._ms1` 会漏 | 候选文件加上 `<root>_m_merge*.ydd` / `_f_merge*.ydd` |
| 6 | **部分角色包里根本没有头**（乐队、杂兵） | 无头人 | 补一套通用头/眼/牙（`GENERIC_HEAD`，manifest 可查） |
| 7 | **有头但没眼球**（如阿贝·麦克莱恩） | 空眼窝 | 补通用眼球，并按"头部包围盒 62% 眼线 + 面部前缘 −3.5 cm"对齐（`GENERIC_EYES_ALIGNED`） |

还有一个**不是 bug 但很坑**的情况：角色专属眼球（如 `cs_abigailroberts_fs1_eyes_000_c0_000_ab`）
本身就是画好的图，不能按遮罩处理——我第一次一刀切合成，反而把她的眼睛弄黑了。现在按名字/内容分开处理。

### 1.2 修法

```
if 眼球贴图是 _999_ab 或判定为遮罩：  → synth_eye() 合成
else（cs_*_eyes_000 这种真图）        → 原样使用
eye_cap                              → alphaMode=BLEND, alpha=0.06（几乎不可见，只留一点湿润感）
```

`synth_eye()` 按通道重建：

| 通道 | 含义 | 合成成 |
|---|---|---|
| G | 眼白 | 白 (0.90/0.88/0.86)，带原图的血管纹理 |
| R | 虹膜盘 | 棕色 (0.28/0.17/0.10) |
| B | 瞳孔 | 近黑 (0.015) |

![眼球遮罩的三个通道](img/eyes/eye_mask_channels.png)
*左 = 原图（荧光绿）；中左/中右/右 = R / G / B 通道：虹膜盘 / 眼白 / 瞳孔*

![合成后的眼球](img/eyes/eye_synth.png)
*合成结果：眼白 + 血管 + 棕色虹膜 + 黑瞳孔*

## 2. 服饰：为什么有些是白模

### 2.1 根因：贴图名差一个变体号

模型里写的贴图名，在解包出来的 `.ytd` 里**不一定存在同名条目**。实测 10 745 个服饰部件：

| 情况 | 件数 | 例子 |
|---|---|---|
| 直接命中 | **9 676** | — |
| `_998_ab` → `_999_ab`（998 是未调色变体） | 9 | `combocoat_mr1_025_c3_998_ab` |
| 同 c，换 999 遮罩 | 80 | `coat_mr1_087_c0_000_ab` → `coat_mr1_087_c0_999_ab` |
| 换 c，同后缀 | 204 | `accs_fr1_012_c0_999_ab` → `accs_fr1_012_c1_999_ab` |
| 换 c + 999 | 81 | — |
| **确实没有** | **695**（6.5%） | `GoreA_MR1_002_c0_000_ab`、`head_fr1_4004_c0_000_ab`（未使用的备用头） |

### 2.2 修法：四级回退 + 部位底色

1. `resolve_tex()` 按 **原图 → 998→999 → 同 c 换 999 → 换 c（0~6）→ 换 c+999** 依次找；
2. 仍然找不到的，按**部位**给一个底色（不再渲染成纯白）：

| 部位 | 兜底色 |
|---|---|
| 头/眼/手/皮肤 | 肤色 (0.62, 0.45, 0.36) |
| 靴/枪套/腰带/皮革 | (0.26, 0.19, 0.13) |
| 金属扣/马刺/链 | (0.48, 0.49, 0.52) |
| 头发/胡须 | (0.16, 0.12, 0.09) |
| 血污 gore | (0.30, 0.06, 0.06) |
| 其它布料 | (0.34, 0.30, 0.26) |

### 2.3 结果

| 指标 | 修前 | 修后 |
|---|---|---|
| 完全无贴图的服饰件 | **920** | **594**（改用部位底色） |
| 有真实贴图 | 5 186 | **5 512**（90.3%） |
| 角色模型里出现白模部件 | 有 | **0**（408 个角色全部有贴图或底色） |

> 剩下 594 件的贴图**在游戏资源里确实不存在同名条目**（多为 gore 血迹、未使用的备用头 `head_fr1_4004`/`9xxx`、
> 少数 DLC 变体）。已确认 22 个 `metaped_textures_*.rpf` 全部解包（17 570 个 `.ytd`），
> 且 `packs_1.rpf` / `update_*.rpf` 里也没有对应文件，不是漏抽。

## 1.5 头发颜色：白发的根因与修法（2026-10-22 追加）

**现象**：夏洛蒂的黑发被导出成**灰白头发**（"白发老妪"）。

**根因**：头发贴图 `hair_gen_999_c0_999_ab` 同样是一张 **tint 遮罩**（均值 (0.20,0.49,0.07) 的绿），
真色来自 `assets_tints.ymt`（PSIN，未解）。之前统一"降饱和"→ 变成中性浅灰 → 白发。

**修法**：用**同一角色的眉毛贴图**当发色来源 —— 眉毛通常是画好的真色，正好等于本人发色。

| 角色 | 眉毛贴图均值 | 得到的发色 |
|---|---|---|
| 夏洛蒂·贝尔福 | (0.015, 0.007, 0.006) | **近黑** ✅ |
| 达奇 | (0.054, 0.042, 0.041) | 深褐黑 ✅ |
| 亚瑟 | (0.212, 0.167, 0.129) | 棕色 ✅ |

实现：`_eyebrow_color()` 取眉色（绿遮罩/过亮则退回深棕），`synth_hair()` 用头发遮罩的**明暗**染上该颜色，
保留发丝层次；胡须同色处理（之前会把达奇的胡子渲染成绿色，也是同一个原因）。

![夏洛蒂·黑发](img/eyes/hair_charlotte_after.png)
*夏洛蒂：黑发，和游戏一致*

![亚瑟·棕发](img/eyes/hair_arthur_after.png)
*亚瑟：棕色，说明不是"一刀切染黑"*

> **仍未解决**：**衣服**的 `_999_ab` 遮罩没有"眉毛"这种可参照物，只能保持中性色
> （夏洛蒂的衬衫因此偏白，游戏里是深蓝花纹）。要还原必须解 `assets_tints.ymt` 调色板。

## 1.6 眉毛下方的白斑：眼球贴图的"眼睑圈"（2026-10-22 第二次追加）

**现象**：`viewer/npc` 头部特写里，眼睛上下、太阳穴一侧出现**纯白色多边形块**，换个角度又看不出来。

**根因（两个叠加）**：

| # | 原因 | 说明 |
|---|---|---|
| 1 | **眼球贴图的外圈被涂成白色** | `Eyes_Gen_*` 的 UV 不只覆盖眼球，还覆盖**眼睑/内眦**那圈网格；`synth_eye()` 把整个纹理铺成眼白（0.90），于是眼睑也被染白 → 从某些角度看就是白斑 |
| 2 | **`eye_cap` 与眼球共面** | 湿润罩 z 0.089~0.101，眼球 z 0.080~0.098，深度几乎重合 → WebGL 里 z-fighting，闪出纯白（底色 1,1,1） |

**修法**：

- `synth_eye(png, skin)` 增加**肤色参数**：眼白区域按 `sclera` 遮罩混白，**遮罩外的眼睑圈混头部贴图平均色**（`_head_color()` 取头部 albedo 均值，阿比盖尔 = (0.674, 0.492, 0.406)）；
- **不再导出 `eye_cap`**（它只是湿润高光，去掉不影响外观，但能彻底消除 z-fighting）。

![修前：眼周白斑](img/eyes/eye_patch_before.png)
*修前（用户截图）：眼睑与太阳穴一侧是纯白多边形*

![修后：阿比盖尔](img/eyes/eye_patch_after.png)
*修后：眼睑回到肤色，只剩眼白/虹膜/瞳孔*

## 1.8 夏洛蒂"变丑"的四个原因（2026-10-23）

对照游戏截图逐项排查，一共四条，前三条可修，第四条是静态导出的固有边界。

| # | 原因 | 证据 | 处理 |
|---|---|---|---|
| 1 | **挑到了"脏脸"头部贴图** | 她有三套头贴图：`c0_001`（满脸泥污，`merge_7` 用）、`c0_002`（干净）、`c0_000`（更脏）；合并组按"完整度"打分时选中了 `merge_7` → 脏脸 | 改为优先使用**独立 `*_head_*.ydd`** 里的标准头部（`CLEAN_HEAD:` 会写进 sources） |
| 2 | **查看器头部特写用 45° 广角贴脸拍** | 45° 近距会把鼻子放大、脸拉宽（"自拍畸变"） | 头部特写改成 **20° 长焦**，全身仍是 45° |
| 3 | **眼球贴图整张铺成白色** | `Eyes_Gen_*` 是 tint 遮罩；之前把虹膜外全部涂成眼白（0.90）→ 两个大白球 | 改为**虹膜以外用头部肤色**，只保留虹膜+瞳孔 → 看起来是正常睁眼 |
| 4 | **这颗头的眼睑在静态姿势里是闭合的** | 把头抬高/压低都不影响：eyeball 缩到 2.7 cm 就完全被眼皮盖住；撑开眼睑又会露出黑洞 | **无法在静态网格上彻底解决**（游戏里靠面部骨骼/形态键睁眼）。当前用"虹膜+肤色"的方案做视觉近似 |

## 1.9 回滚记录：一次把角色改坏的改动（2026-10-23）

### 出了什么问题

为了让夏洛蒂的"脏脸"变干净，我加了一条规则：**优先用独立的 `*_head_*.ydd` 替换头部网格**。结果翻车：

| 症状 | 原因 |
|---|---|
| **亚瑟的脸没了**（只剩眼睛和牙齿浮着） | `player_zero_head_001.ydd` 的顶点在**另一套局部空间**，直接换进去让头下沉到 y=1.32（胸口位置），被衣服挡住 |
| **夏洛蒂变成老太婆** | 独立头文件里那份贴图（`head_002_c0_000`）是**苍白/憔悴**版本，不是标准脸 |

### 处理

1. **整段删除**跨文件替换头部的逻辑（`③-e`），恢复"用当前服装组合自带的头"；
2. 代码里留了注释，说明为什么不能这么换：
   ```
   # ③-e （已回滚）不再跨文件替换头部网格：
   #      *_head_*.ydd 的顶点是另一套局部空间，直接换会让头下沉 7 cm（亚瑟的脸就是这么没的）
   ```
3. 顺带修了一个真 bug：**`eyes_cap` 没被过滤**（之前只过滤 `eye_cap`）——
   亚瑟的"红眼/青蛙眼"就是这层罩子盖在眼球上；现在 `eyes?_?cap` 一起剔掉。

### 结果

- 亚瑟：脸回来了，**蓝眼睛正常**；
- 夏洛蒂：黑发、五官恢复（回到"脏脸"那版，但不再老态）；
- 408 个角色全部重导，`index.html` 重建（glb 带 `?v=` 时间戳）。

> 教训：**不要跨文件替换网格**。要换外观只能换贴图（UV 相同才行），换网格会带进坐标系/绑定差异。
