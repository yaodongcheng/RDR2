## ① 远景 LOD 偏稀（瓦伦丁最明显）——不是没提取，是名字丢了

（`val_02_slod` … `val_07_slod`，9 块约 1.58 万三角面）**都在场景里**。

### 三条根因

| # | 根因 | 实测数字 |
|---|---|---:|
| 1 | `names.txt` 里有 `X_children`、**没有父名 `X`** | 10,621 个 children → **9,615** 个父名缺失 |

| 3 | 少数 area LOD 模型不在模型库 | `lm_09_10_val_es_slod3` 等 |

根因 1 里：**158 个父块模型在库**（就是全图城镇街区 LOD：`bla_blk01_slod` / `cal_02_slod` /
`cle_01_a_slod` / `cor_workers01_slod` / `cvb_01_*_slod` / `val_02..07_slod` …）；

## ② 室内地面贴花单独成类（`int_decal`）

### 为什么

室内件对象名一律 `i_<hash>`，`classify_name` 判不出；`scene_interiors.py` 原来硬写
`cls_key='part'`。于是「破洞补丁/滴渍/泥污」这类贴花混在 `part` 里，材质 alpha 没接、
按不透明渲染 → 深色实心片（用户看到"纯黑"）。

### 做法

- 新增第 22 类 `int_decal`（中文：室内地面贴花），进 `DEFAULT_HIDDEN`。
- `scene_interiors.py` 建完 mesh 后按**模型贴图名**判：`_dc_` / `decal` / `holepatch` / `drip` / `stain`。
- 集合树：`ENTITIES/C_int_decal_室内地面贴花/int_decal|<地块>`，默认隐藏，N 面板可单独勾开。
- 与室外 `decal` **分开**：两者贴图/材质问题不同，要能分别开关。

### 实测

- `sod.blend` 试跑：224 件室内 → 3 件 `int_decal`，集合 `hide_viewport/hide_render = True`。
- 全 56 张场景扫一遍：**368 件**会被分出来（243 种贴花贴图）。

### 注意

现有 56 个 blend 还是旧分类 —— 室内是在建场景最后一步写的 `cls_key`，**不重建不会变**。
只改现有产物的话需要另写后处理脚本（当前没有）。
