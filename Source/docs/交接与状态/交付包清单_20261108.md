## 5. 如果要让「表」也进 git

当前 `.gitignore` **不放行 `.csv`**。两个选项：

1. **只进关键小表（推荐）**：在 `Source/.gitignore` 加 `!*.csv`，把 `world_meta.json`（1.5 KB）、`settlements_world_v2.csv`（6.7 KB）、`material_textures.csv`（894 KB）、`models_export.csv`（3.8 MB）复制到 `Source/docs/交接与状态/handoff_snapshot/`；约 **4.7 MB**。
2. **全量表进 git（不建议）**：再加 `model_materials.csv`（11 MB）/ `asset_import_*`（7 MB）/ `textures_export.csv`（2.5 MB），总计约 **21 MB**，且每次重跑都会产生大 diff。

模型（14 GB）、贴图（5.8 GB）、blend（41 GB）**永远不进 git**。
