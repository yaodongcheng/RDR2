## 2. 关键口径（接手先读）

### 2.1 地形

- **大地图高度 = `01_plateau_plain` 纯重采样**。01 只保留“西北/东南地图外延扩展”，02 的河床雕刻不用；**不做任何水面改造**（旧 B 方案：垫陆地 / 抬低地 / 挖海床 / 岸坡，已从脚本删除）。
  - 脚本自检：`gen_rdr2_terrain.py` / `gen_rdr2_sdn_terrain.py` 写图前重算一遍重采样，差异 >0.1 mm 直接失败 —— 防止水/陆地改造回流。
- 大地图 16×12 @48 = 768×576；高度图 4097×3073；Import Heightmap **scale 50.0 / offset 0**；水位（若启用）`0.684620` units。
- **圣丹尼斯 = `scene_native` 纯重采样**。真实 far_rect 3328×3968；正方形节点约束下取 **13×15@256 = 3328×3840**（北边裁 128 m，活动区 884.8×587.9 完整保留）；Import **scale 193.651 / offset −20.289**；z 为绝对米；水位 39.5 m（如需全局水）。
- **彩图不是地形层，是 vista colormap**：
  - `vista_tileset="none"` + `vista_diffuse_name=<纹理名>` + `vista_diffuse_blend_type="1"` + `vista_diffuse_blend_amount="1.000"` + `colormap_detail_level="-1"`；
  - `blend_type=1` = 层颜色 × 彩图 ⇒ 层 `diffusemap` 必须是 **`plain_white`**，normal/spec/area/displacement 设 `none`；
  - **不能挂 `WorldMap` tileset**（虚拟纹理路径会忽略 VistaDiffuse）；
  - UV = `world_xy / terrain_size`，`v=1-y`；整张只铺一次；图集行 0=北、列 0=西；
  - 彩图纹理非 2 次幂**不能生成 mipmap**（编辑器警告）；用户 2026-11-09 裁定大地图保留 8192×6144（4:3），接受该警告。
- **地形层水（局部水）= `water_ground` + `gloss_s` + mask**：只是“画出来的水”，不会动、没有水深/透明/反射；颜色 = 层颜色 × 彩图；真水要 `water_plane`（每块水体一个 z，支持多水位）。

### 2.2 材质与导入

- **ModKit 导网格不建材质**（官方文档）⇒ 先建材质、再导 TRF；事后补材质不会回填。
- 离线生成：`tpaccli editormeta --genmats3 <texdir> --mtlref <3槽参考> --matmap <csv> --out <dir>/x`（新增模式）。
  - `gen_rdr2_sdn_materials3.py` **不再创建 `_tex.tpac`**；缺中性贴图或任何 albedo 贴图时直接失败并列出要导入的 PNG（不再静默用白色/自动写 Assets）。
  - 参考材质要 **3 槽**（Diffuse 0 / Normal 2 / Specular 4），shader `pbr_metallic`，flags `use_specular,do_not_use_vertex_color_as_occlusion`；
  - 生成时必须**字节级替换 RawMeta 里的 GUID**，只改字段无效。
- **TRF 导入会把网格名末尾的 `_lod` / `_lodNNN` 去掉**，再生成 MetaMesh 资产名：
  - `new_res_doctor_int_lod` → `new_res_doctor_int`
  - `new_gar_08_cistern_lod001` → `new_gar_08_cistern`
  - prefab 的 `meta_mesh_component name` 必须用**去后缀后的资产名**。
  - ⚠️ `Assets\...\*_geo.tpac` 的**文件名仍带 `_lod`**，别拿文件名直接和 prefab 引用比（会假报缺件）。
- 🔴 **TRF 的 UV 必须是 `1 - 原始 .ydr v`，且全档一致**：引擎按左下原点采样；翻转统一在 `read_mdl()` 做一次，`make_part()` 不再翻。旧版只在 `make_part()` 翻 ⇒ **LOD0 例外**（近处贴图错位、花园十字消失）。详见 `README_骑砍2交接.md` 的 TRF 条目。
- 贴图源路径必须 **ASCII**：FreeImage 打不开 `Debug\RD2构造相关\...`（中文路径），会报 `FreeImage_Load: failed to open file`。
- 贴图/资产**由用户导入**；Claude 不往 `Assets\` 写资产（本轮越界过一次，已记）。
- 导入对话框“全勾”是硬编码默认，**没有配置文件**；对静态 TRF 多余选项是 no-op。

### 2.3 prefab

- `continent_lod_split_v25(_river).blend` 的“合并”= **按据点分组**，每个据点集合里仍是独立碎片对象（sdn 185 个），不是单一网格；每个碎片有 LOD0-6。
- prefab XML：root + children + `<meta_mesh_component name="<MetaMesh资产名>"/>`；每个子节点位置 = `pos_local`，旋转 = 四元数→Euler（引擎 `Mat3.GetEulerAngles` 反式：`x=asin(f.z)`、`y=atan2(-s.z,u.z)`、`z=atan2(-f.x,f.y)`）。

- 地图距离会选 LOD5/6，花园等小细节消失属正常；不要拿“完整大陆 blend”和“LOD 碎片 prefab”比细节。

## 3. 未决问题（按优先级）

### ~~P0 花园十字在引擎里看不到~~ → **已解决（2026-11-09）**

- **根因**：不是 U/V 对调，也不是贴图旋转；是 `export_rdr2_trf_lod.py` 里 **LOD0 漏翻 V**。旧逻辑只在 `make_part()` 里做 `co[:,1] = 1-v`，而 LOD0 直接 `arrays.append((pos,nrm,uv,tri))` 用了**原始 .ydr 的 v** ⇒ 同一个 TRF 里 LOD0 与 LOD1-6 差一个 `1-v`（实测 972 个对位顶点里 971 个翻转）。
- **判据（可复用）**：同一块地出 4 个单档 TRF（raw / vflip / uflip / uvswap）逐个导入，只有 `vflip` 出**正圆**花园。花园在贴图里是 52×24 px 的横椭圆；正确 UV 落地 = 39.0×38.5 m（比值 1.01）；U/V 互换或转 90° 会变成 2.3:1 的横椭圆。
- **修法**：翻 V 统一到 `read_mdl()`（全档一次），`make_part()` 不再翻；重出 184 个 sdn TRF → 重导 → 实机确认（近景/远景都正常）。
- 测试件与离线预览：`D:\BrainMaker\大镖客2解包分析\_scratch\uv_check_20261109\`。

## 5. 本轮教训（已同步到 wheels/pitfalls）

1. **计划与脚本冲突时，先读计划**：计划已写“旧 B 方案废弃”，脚本却还留着；照脚本跑 = 白改地形。旧注释不是现行口径。
2. **不擅自处理水面/地形**：用户只保留 01 外延、不要 02 刻河，也不要在高度图里做水改造。
3. **不往 `Assets\` 写资产**：贴图/资产由用户导入；Claude 只放 `ImortReady` 并给导入步骤。
4. **先材质后网格**：ModKit 导入网格时绑定材质，事后补材质不会回填；删 `_geo` 重导才行。
5. **名字映射必须验证**：TRF 去 `_lod`/`_lodNNN`；层名/资产名不是模型名。
6. **路径避免中文**：FreeImage 打不开 `Debug\RD2构造相关\...`；源图放 `AssetSources`（ASCII）。
7. **比较要同源**：完整大陆 blend vs LOD 碎片 prefab 不能比细节；地图 prefab 是 1:14 缩略，小件会消失。
8. **一次只改一个变量**：V 翻转用“翻转贴图 A/B”，别同时改 UV/材质/贴图。
9. **踩坑要固化进脚本**：地形纯重采样自检、材质缺贴图硬失败、prefab 意外缺件硬失败；不要只写文档。
10. **TRF 的 UV V 约定必须全档一致**：引擎左下原点 ⇒ 写 `1-v`；翻转只在 `read_mdl()` 做一次，别在某个分支里单独翻（旧版 LOD0 就是这么漏的）。
11. **“贴图方向不对”先用几何判据定性**：找贴图里的圆形/文字特征做 A/B（4 个单档变体），别凭观感猜 U/V。
12. **删 ModKit 资产只能在编辑器里删**：在外面删 `Assets\` 文件会让编辑器启动崩溃（索引/引用还在）。救急 = 备份 MD5 → prefab 改名 `.xml.disabled` → 注释场景里引用它的实体 → 恢复后逐文件核对 MD5。
13. **自动点击脚本别用“等句柄消失”做去抖**：Windows 复用 HWND；用「句柄 + 时间间隔」（v5 = 900 ms）。
