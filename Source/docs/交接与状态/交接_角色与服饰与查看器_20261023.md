## 2. 怎么用

### 2.1 查看器（唯一入口）

```
双击根目录「打开查看器.bat」
→ http://127.0.0.1:8788/    （端口被占用会自动顺延 8789~8792，看窗口里打印的 URL）
```

首页入口：服装 3D 试衣间 / 角色模型 3D / 服饰清单 / 角色动画 / 进度预览 / 数据总览 / 世界地图 / 任意地点扎营 / 城镇预览 / 地图标定。

> **页面必须走 http**。直接双击 html 会白屏（浏览器拦 ES 模块与 glb），页面里已加红字提示。

### 2.2 Blender 看单个角色

```
双击 deliverable/blender/characters/cs_rockyseven_widow_fs1.blend
Numpad 0 进相机；选中 Camera_Full 后 Ctrl+Numpad 0 切全身
```

换角色：

```bash
"C:/Program Files/Blender Foundation/Blender 5.2/blender.exe" -b \
  -P tools/make_character_blend.py -- \
  export/npc/cs/<角色ID>/<角色ID>.glb \
```

### 2.3 重跑管线

```bash
# 角色（含眼睛/头发/眼睛罩处理）
```

## 3. 关键经验（这一轮踩过的坑，按重要性排）

### 3.1 RDR2 的贴图**大量是"遮罩"而不是颜色**

判据：名字带 `_c<N>_999_ab`，或贴图整体是**一片荧光绿**。

| 部位 | 处理 | 原因 |
|---|---|---|
| **眼球** | 按通道合成：R=虹膜、G=眼白、B=瞳孔；**虹膜以外用头部肤色** | 直接当颜色=荧光绿；降饱和=灰球；整张铺白=两个白球 |
| **头发/胡须** | 用同一角色**眉毛贴图**的平均色当发色，再用头发遮罩的明暗染色 | 夏洛蒂眉毛均值 (0.015,0.007,0.006)=近黑，正好是她的发色 |
| **衣服** | 只能中性色（暂缺） | 衣服没有"眉毛"这种可参照物，真色在 `assets_tints.ymt`（PSIN，未解） |

> 眉毛取色的实测：夏洛蒂近黑、达奇深褐黑、亚瑟棕色——**不是一刀切**。

### 3.2 按贴图名去重会**丢部件**

一张贴图可能挂多个 drawable（头 + 鼻/耳）。杰克的 `Head_000` 被去重成 5 cm 的小块 → 头没了、眼球外凸。
**去重键必须是 `(贴图名, drawable hash)`**。

### 3.3 **绝不跨文件替换网格**

我为了让夏洛蒂用"干净脸"，把 `*_head_*.ydd` 的头网格替换进她的组合——结果：
- `player_zero_head_001.ydd` 的顶点是**另一套局部空间**，亚瑟的头顶下沉到 y=1.32（胸口），**脸直接没了**；
- 该文件里另一份贴图是"苍白憔悴版"，夏洛蒂显老。

**换外观只能换贴图（且 UV 必须一致），换网格会带进坐标系/绑定差异。**

### 3.4 `eye_cap` / `eyes_cap` 必须剔除

它是"湿润高光罩"，与眼球**共面**（z 0.089~0.101 vs 0.080~0.098）：
- WebGL 里 z-fighting → 眼周白斑；
- 亚瑟的 `Eyes_Cap_000` 是红色 → 红眼/"青蛙眼"。

过滤要用正则 `eyes?_?cap`（只匹配 `eye_cap` 会漏 `eyes_cap`）。

### 3.5 眼睛/头可能在"别的文件"里

| 情况 | 例子 | 兜底 |
|---|---|---|
| 眼睛在另一个 merge | 杰克（merge_4）、艾芙琳（merge_8） | 扫描该角色所有文件补眼/牙 |
| 头在**不带性别后缀**的变体 | 特里劳尼 `cs_josiahtrelawny_m_merge.ydd` | 候选文件加 `<root>_m_merge*.ydd` / `_f_merge*.ydd` |
| 包里根本没有头 | 乐队、杂兵（28 个） | 补通用头/眼/牙，manifest 记 `GENERIC_HEAD` |
| 有头没眼球 | 阿贝·麦克莱恩等 7 个 | 补通用眼，按"头高 62% 眼线 + 面部前缘 −3.5 cm"对齐，记 `GENERIC_EYES_ALIGNED` |

### 3.6 其他小坑

| 坑 | 现象 | 处理 |
|---|---|---|
| 儿童眼球按成人尺寸 | 杰克"大头娃娃" | 按身体高度等比缩放 |
| 帽子悬浮 | 帽檐在头顶外 | 按"发顶下 3 cm"下压 |
| 查看器 45° 广角拍脸 | 鼻子放大、脸拉宽（"自拍畸变"） | 头部特写改 **20° 长焦**，全身仍 45° |
| glb 缓存 | 改了模型刷新还是老样子 | 模型 URL 加 `?v=<时间戳>` |
| 列表只渲染 600 条 | 只看到配饰，翻不到衣服 | 分批加载 + 大类/性别筛选 |
| bat 用中文 + GBK | 命令被截断/乱码 | **bat 只写 ASCII**，端口探测 + 等端口就绪再开浏览器 |
| 地名手译 | "马蹄铁眺望"（游戏里根本没有） | 一律查 `global.yldb`，见 §3.7 |
| 据点编码想当然 | 朗尼小屋指向空地 | 用**模型名前缀**反查坐标（`lon_01_home_ext`） |

### 3.7 译名必须用游戏**自己的**本地化

```
data_0.rpf → data/lang/{american,chinesesimp}_rel.rpf → global.yldb
同一 hash 在中英两份里各一条字符串 → 直接配对（21 733 条）
```

已纠正 **24 个地名 + 33 个人名**，例如：马蹄铁眺望→**马掌望台**、吊狗牧场→**垂犬牧场**、
裂齿矿洞→**豁牙裂口**、瓦匹提→**瓦匹缇**、阿比盖尔→**艾比盖尔**。

工具：`tools/official_name_map.py`（查）、`tools/apply_official_names.py`（批量替换）。
