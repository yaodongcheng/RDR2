图例 / 怎么读（大白话）
橙色方块 = 能走的地方（矩形 1）：每个据点一块，互相不重叠。
细橙线 = 实际能走边界：比矩形略大；由地盘线/海岸决定。矩形只是干净表示。
灰色大框 = 远景（矩形 2）：点名字才出现；一定包住橙色方块；只做背景，不能走；可重叠。
绿色虚线 = 野外营地的一张地图：3,072 m；玩家在框内扎营 → 载入它。
绿色实心 = 营地里能走的地方：已切掉地图外面。
彩色地盘 = 地盘划分：这块地归谁；不是能走的地方，也不是地图。只在“地盘”页显示。
深色虚线 = 大镖客地图边缘；外面不能走。
黄星=城市 · 蓝菱=城堡 · 绿三角=藏身处
黑点 + 小字 = 小据点（村子/营地/点位，22 个）：没有自己的地图；住在野外营地地图里；点它看所在营地。
