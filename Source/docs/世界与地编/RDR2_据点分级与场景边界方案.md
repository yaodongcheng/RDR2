## 1. 57 张子场景的分工

1. **据点地图 44 张**：玩家点据点、或走到据点能走范围里 → 载入**这个据点自己的场景**。城、堡、村、营地、野外点位、藏身处一视同仁，**没有“小据点寄存在野外地圖里”这回事**。
2. **野地地图 12 张**：铺在整张有效地图上，分成 12 块横平竖直的矩形。玩家在大地图任意位置扎营 → 看他落在哪块矩形 → 载入那张野地场景，出生点按真实坐标换算。
3. **瓜玛岛 1 张**：不在大地图框内，走独立跳转（两处合并）。

**为什么野地要单独开图，而不是塞进据点图**：据点的场景只有 512–1,536 m，装不下两个据点之间几公里的荒地；野地场景 1,400–4,352 m，正好盖住“离任何据点都有一段距离”的地方。

### 1.0 野地和据点的关系（2026-11-03 第二轮裁定）

- **野地矩形不挖据点**：野地 = 整片真实陆地分完，**据点那几块也算在野地里**。原因是挖掉 44 个据点矩形会把陆地切碎成互不相连的碎块 + 洞（几何上的必然），地图会碎成渣。
- **进入靠提示**：玩家在野地场景里走进某个据点的能走范围 → 弹「是否进入 XX」→ 切到据点自己的场景。
- **野地场景里的据点用远景碎片**（`C_lod_远景碎片`）表现，不做高清；高清只在据点自己的场景里。
- 重叠是设计内的：野地 ∩ 据点 = **8.44 km²**（据点全在地图区内）；判定时**据点优先**。

### 1.1 地图区 / 地图外（2026-11-03 用户裁定）

- **真实地图 = 官方地图上「有画面」的那一片**（`地图下载/大陆地图_缩略.jpg`，配准框 `[146,388,4804,3851]`）。空白羊皮纸（河流以南、西北角、东侧）是**地图外**，只能做远景。
- 判定：缩略图上「局部没有纹理 + 颜色=羊皮纸底色」= 空白；剩下的最大连通块 = 地图区。
- **水面也算可走**（湖、河、海都是能移动的区域），所以地图区 = **陆地 40.03 + 水面 8.10 = 48.12 km²**，野地矩形把水面一起分完。
- 地图外 **38.19 km²** 不进任何能走范围，只做远景；页面上打斜线标注「地图外 · 官方地图上没有画面 · 不可走 · 只做远景」。

## 2. 两层：玩家活动区 + 远景范围

每个场景只有两个圈：

| 层 | 是什么 | 能不能走 | 里面放什么 | 地形精度 |
|---|---|---|---|---|
| **玩家活动区** | 玩家走得到的地面。据点 = 建成区 + 屏障带 + 城边空地；野地 = 那张矩形 | ✅ 能走，走到边上被 `border_hard` 挡住 | 高清建筑、碰撞、寻路、NPC、交互 | 4 m 网格 |
| **远景范围** | 活动区每边再往外扩一圈 | ❌ 不能走、不碰撞、无寻路 | 同源低精度地形 + blend 里现成的 `C_lod_远景碎片` | 16 m 网格 |

```
远景范围（不可走、不碰撞）：低精度地形 + 建筑/地标剪影，一直铺到雾里
└─ 玩家活动区（引擎硬边界在这里，走不出这个圈）
   └─ 能走范围：高清建筑 / 碰撞 / 寻路 / NPC
```

**一句话**：**活动区是玩家能走的地方；远景只做背景。**

**两条硬约束**（生成器已自动保证）：

1. **活动区宽高、每边外扩都必须是 128 的倍数** —— 地形按 128 m 节点整块切；不取整的话，一个节点会一半是细地形一半是粗地形，切不出来。
2. **据点的能走范围离活动区边缘每边至少 64 m** —— 这圈用来种屏障（密林/岩壁/水/围墙），让"走到边被挡住"看起来自然。不够 64 m 的，生成器自动把活动区加一档。

> 旧文档里的「缓冲带 B」不再单列：它就是活动区里城区之外那部分地，和活动区是同一个圈。

## 3. 硬规则与自检

**规则（2026-11-03 用户裁定，改方案也不能破）**

1. **据点能走范围各自不重叠**（每个是外切矩形）；据点有自己的地图，从大地图点它进的是它自己的场景。
2. **野地能走范围 = 12 个横平竖直的矩形**（用户手画），铺满地图区；**野地矩形包含据点范围、矩形之间宁可重叠**。
3. **据点能走范围 ∪ 野地矩形 = 整张有效地图**；野地 ∩ 据点是**设计内的重叠**（据点优先），不再要求两两不重叠。自检要求：覆盖无缺口、据点两两不重叠。
4. **活动区和远景范围可以重叠**（不同 Mission，玩家一次只进一张）；只要能走范围不重叠。
5. **坐标 → 场景**：落在据点能走范围内 → 进该据点地图；落在野地矩形内 → 进该野地地图；都按坐标换算场景局部位置。
6. **41 / 46 两版作废**；不许再出现“小据点并进野外、村庄跳去野地”的写法。

### 5.2 这套矩形怎么来的

1. 初始由「地图区外接框分等面积网格」自动生成 17 块；
2. 用户在 `regions_viewer.html` 的**编辑模式**里手改：删 5 块、改大小、补缝（矩形画法 + 吸附 + 贴合邻居），定稿 12 块；
3. 自动对齐：把相差 2–40 m 的边**归并成同一条线**；
4. 剩下 2 m 级的缝：**一律用重叠吞掉**。

## 6. 坐标 → 场景（玩家怎么被放进哪张图）

```
点据点 / 大地图扎营 / 开战，拿到世界坐标 (x, y)
  ↓
1. 落在某个据点的能走范围里？
   ├─ 是 → 进该据点场景：场景内坐标 = (x − 据点中心x, y − 据点中心y)
   └─ 否 → 继续
2. 落在某个野地矩形里？
   ├─ 是 → 进该野地场景：场景内坐标 = (x − 野地中心x, y − 野地中心y)
   └─ 否 → 水面 / 地图外，不可走，不进场景
```

**在野地场景里走进据点**：野地矩形包含据点范围，所以玩家在野地场景里会走到据点那一块。走到据点能走范围的边界 →
屏幕上弹「是否进入 XX」→ 是则切到据点自己的场景（落点按真实坐标换算）；否则停在边界，继续在野地里。

**要点**

- 所有场景的 **Y+ 朝北**，1 单位 = 1 m（2026-10-26 实机确认）。
- **两张野地场景之间不直接连通**：走到场景边缘 = 回大地图；要换区域就回大地图再扎营。
- **据点 ↔ 野地**：从城门出去 → 用城门外坐标落在哪个野地矩形决定进哪张野地；反过来走到据点能走范围边界 → 进据点场景。
- **据点能走范围是唯一的进入判据**，不是活动区。

## 8. 远景范围怎么用 blend 里现成的“远景碎片”

**不用自己从 `bldg/struct/veh` 重新裁、也不用重新减面。** 每个 region blend 里已经分好了 `C_lod_远景碎片` 集合（对象自定义属性 `cls='远景碎片'`、`cls_key='lod'`、`tile='wild2000_XX_YY'`），直接拿它当远景主体。

**实测（`wild2000_05_02`，圣丹尼斯所在块）**：24,763 个对象里 `C_lod_远景碎片` 203 个 / 14.2 万面 / 76 材质；19 号块（`wild2000_04_02`）是 512 个 / 36.4 万面。**每块的量差别很大，按实际相交的块算，不要外推。**

| 集合 | 是什么 | 远景怎么用 |
|---|---|---|
| `C_lod_远景碎片` | 建筑/道具/铁路的现成低模替身 | ✅ 直接用；近处不再减面，远处按距离剔除 |
| `C_terrain_cell_地形块` | 地形本身的网格 | ❌ 不用；远景地形从解包高度图重新采样，接缝才对得上 |
| `C_terrain_lod_地形远景块` | 地形自己的超低级替身 | 有就用它做远景地形；没有就用高度图降采样 |
| `C_veg_植被` | 植被 | 可选；billboard 或直接烘进地形色 |

**做法**

1. 以场景中心为中心，裁到**远景范围**那么大（矩形）；
2. 找出相交的 region 块，取每块的 `C_lod_远景碎片`；
3. 排除**活动区以内**的对象（那里是高清建筑，不能和低模替身叠在一起）；
4. 按材质合并/分批，**不需要再减面**；
5. 近处（距活动区边 <1.5 km）用全量；更远按距离剔除或再减面 50%；
6. 输出静态网格挂 prefab；**不碰撞、不寻路、不投影**。

**坐标系注意**：region blend 是独立块场景，原点在块中心；`C_lod` 的对象原点是 `(0,0,0)`、顶点是块局部坐标。导出到场景时要**加回块的世界中心，再减场景中心**。

**预算修正**：按块实测 14–36 万面。圣丹尼斯远景 4,096 / 活动区 1,536 → 那一圈 14.4 km² ≈ 3–4 块 → 42–144 万面；野地 `wild_04` 远景 6,400 × 3,840 → 那一圈 ≈18 km² ≈ 4.5 块 → 63–162 万面。目标 **≤80 万面**：近处全量，远处减面 50% 或只留地标。

**验收**：站在活动区边缘朝外看，画面里是连续地形 + 建筑/铁路/船剪影，一直铺到雾里；关掉远景范围是明显的“地形到此为止”。

1. 碎片包围盒中心落在据点「能走范围」`P` 多边形里 → 归该据点。
2. 否则，**建筑类**（建筑/道具、室内、大区块；**排除铁路与植被**）碎片，若**包围盒**与

2.5 **合并 LOD 跨 ≥2 个据点**（与各自的 `P` 重叠都 ≥ max(自身面积 5%, 10,000 m²)）

3. 否则，中心落在某块野地 `P` 里 → 归该野地（野地互相重叠时取中心最近）。
4. 否则，中心落在某块野地**远景范围**（`FW/FH`）里 → 归该野地。
5. 否则，离瓜玛两个据点中心 ≤ 2,500 m → 归最近的那个瓜玛场景。
6. 都不满足 → `none`（本次 0 个）。

**排除与缺口（照单核对，别当 bug 再查）**

- **地形远景块不算远景碎片**：`terrain_lod` **31 个**，只认不带 `area_` 的
  `<网格前缀>_<行>_<列>_slod<N>`。🔴 带 `_area_slod` 的是**建筑/道具的整区合并 LOD**
  （贴图是建筑图集、含栏杆件），属于远景碎片，已计入上面的 2,324。
- 解包里 **2,573 个** `lod` 实例（按当前名字规则），其中 **312 个没有网格**
  （摆不出来，和「817 个 archetype 缺模型」同一类），主表里没有它们。

**分组怎么用**

- **一个据点一组**，组内按 `sub_group` 分 5 类：`bldg` 建筑/道具 · `interior` 室内 ·
  `rail` 铁路与地形格 · `veg` 植被 · `block` 大区块。
- 圣丹尼斯的整块 `new_area_slod4` 已切开，它拿到的是 `new_area_slod4__split_sdn`
  （792 × 588 m / 4,232 面）；西西卡拿到 `__split_sis`（317 × 243 m / 292 面）。
  拉凯虽然与整块 bbox 重叠，但块里没有拉凯的几何（切完是空的），它仍只有小鸡舍那 1 件。
- `gx/gy/gz` = 世界坐标 − 组锚点（锚点 z = 高度图地面高程；瓜玛没有大陆高度图，用碎片底面中位数）。
  骑砍2 侧拼 prefab 直接用这三个数，不用再算世界坐标。

| 大场景自动寻路太慢 | P0-4 不过 | 关自动寻路改烘焙，或把野地矩形改小 |
| 远景投影拖帧 | 帧率掉一半 | 远景全部 `no_shadow`，只留近景 50 m 投影 |
| blend 碎片缺模型 | 远景出现空洞 | 用同尺寸档最近模型顶替；只影响剪影 |
| 矩形被邻居切得太狠 | 两个据点挨得近，外切矩形互相切，把一方切小 | 只沿重叠区中线切、保留最小 40 m；两个都还完整。若确实太小，调 `settlements_plan.csv` 的 `size_w/size_d` |
| 能走范围里有大片水面 | 玩家能走到河里 | 码头/堤岸保留，其余在水边设屏障 |

## 13. 手工调整：页面上的「编辑模式」

**入口**：`docs/世界与地编/regions_viewer.html`（双击用 Chrome 打开）→ 左上角点「**编辑模式：关**」→ 变成「开」。

> 同一个页面：不开编辑 = 只读汇报页；开了编辑 = 图形编辑器。**没有第二个页面。**

| 能改什么 | 怎么改 |
|---|---|
| 据点的**能走范围** | 点选据点 → 方框出现 8 个把手 → 拖角/边改大小；中间圆点整体挪 |
| 据点的**玩家活动区 / 每边外扩** | 左侧面板直接改数字（步长 128），远景范围自动算 |
| 野地的**分界（矩形）** | 切「野地」→ 点选一片 → **拖 8 个把手改矩形**、中间圆点整体挪；「按外接矩形」把现有形状一键变成外接矩形 |
| 野地的**分界（多边形）** | 同上，但沿用原来的多边形顶点（拖顶点改） |
| 野地的**每边外扩** | 面板直接改（步长 128）；**活动区由矩形自动算**，改形状就跟着变 |
| **新建野地** | 编辑模式 → 左上角「**＋新建野地**」→ 在视野中心生成一块 2,000 × 1,500 的矩形，自动选中，拖边调整 |
| **删除野地** | 选中野地 → 「**删除这个野地**」；总数会立刻跟着变（卡片和页签同步） |

编辑模式下还可以：**滚轮缩放、空白处拖动平移**、放大/缩小按钮。

**对齐（2026-11-03 新增）**

- **吸附**：拖据点边/角时，离别的据点边、自己活动区的边 **30 m 内自动咬住**（画面上出橙色虚线提示）；拖野地顶点时，离别的野地顶点、据点矩形角点 30 m 内也咬住。工具栏「吸附：开/关」可切。
- **一键贴合邻居**：点「**贴合邻居**」→ 把所有相距 **60 m 内**的据点边直接对成同一条线（每对边取中线），画歪的也能一次对齐成严丝合缝。改完记得导出。

**野地也可以画成矩形**（2026-11-03 新增）

- 野地选中后：「**重画矩形**」在地图上拖一个矩形；「**按外接矩形**」把当前形状一键变成它自己的外接矩形。之后拖 8 个把手就能改。
- 工具栏「**野地全转矩形**」：一次把所有野地切成**等面积的矩形**，铺满整个地图框、重叠 0、空缝 0；之后拖边微调（会吸附邻居）。
- **活动区由矩形自动取整到 128**，不用手填；面板上只显示结果。
- 矩形之间**允许重叠**（矩形不可能既铺满不规则地图又互不重叠）：脚本会报告重叠面积，但不再判失败；判定按「离哪个野地中心近」。
- 超出地图区（官方地图空白处）的部分会被裁掉——那部分本来就不能走。

**改动怎么保存**（2026-11-03 补）：

- 每改一次（拖完、改完数字）**自动存到浏览器本地**（localStorage），刷新 / 关标签页都不丢；下次打开自动恢复，顶部徽标显示「改动 N 项（未导出）」。
- 有未导出的改动时关页面，浏览器会弹「确认离开」。
- 「全部重置」会同时清掉本地缓存。
- 🔴 **本地保存 ≠ 生效**：页面写不了磁盘，**必须**点「导出改动」拿到 `scene_overrides.json`，放到 `_scratch/settlement_plan/` 再重跑脚本。

**改完怎么生效**：

1. 点「导出改动」→ 得到 `scene_overrides.json`（只含改过的项）；
2. 放到 `D:\BrainMaker\大镖客2解包分析\_scratch\settlement_plan\scene_overrides.json`；
3. 重跑 `build_scene_division.py` → `build_settlement_map.py`；
4. 脚本会把人工图形裁进地图区、报重叠/缺口；`PASS` 就说明还能自洽。

> 人工多边形是 0.1 m 取整的，允许 500 m² 级的对不齐（自检已放宽）。撤销：删掉 `scene_overrides.json` 重跑，回到自动结果；页面上也有「全部重置」。
