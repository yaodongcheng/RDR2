## 1. 58 张地图的分工

1. **据点地图 44 张**：玩家点据点、或走到据点 P 里 → 载入**这个据点自己的场景**。城、堡、村、营地、野外点位、藏身处一视同仁，**没有“小据点寄存在野外地圖里”这回事**。
2. **野地地图 17 张**：铺在「整张有效地图 − 44 个据点 P」剩下的陆地。玩家在大地图任意位置扎营 → 看他落在哪个野地 P → 载入那张野地场景，出生点按真实坐标换算。
3. **瓜玛岛 2 张**：不在大地图框内，走独立跳转。

**为什么野地要单独开图，而不是塞进据点图**：据点的场景只有 384–1,536 m，装不下两个据点之间几公里的荒地；野地场景 3,072 m 起步，正好盖住“离任何据点都有一段距离”的地方。

### 1.0 野地和据点的关系（2026-11-03 第二轮裁定）

- **野地 P 不挖据点**：野地 = 整片真实陆地按 17 个中心分完，**据点那几块也算在野地里**。原因是挖掉 44 个据点矩形会把陆地切碎成 95 块互不相连的地 + 94 个洞（几何上的必然），地图会碎成渣。
- **进入靠提示**：玩家在野地场景里走进某个据点 P（矩形）→ 弹「是否进入 XX」→ 切到据点自己的场景。
- **野地场景里的据点用远景碎片**（`C_lod_远景碎片`）表现，不做高清；高清只在据点自己的场景里。
- 重叠是设计内的：野地 ∩ 据点 = **8.37 km²**（据点全在地图区内）；判定时**据点优先**。

### 1.1 地图区 / 地图外（2026-11-03 用户裁定）

- **真实地图 = 官方地图上「有画面」的那一片**（`地图下载/大陆地图_缩略.jpg`，配准框 `[146,388,4804,3851]`）。空白羊皮纸（河流以南、西北角、东侧）是**地图外**，只能做远景。
- 判定：缩略图上「局部没有纹理 + 颜色=羊皮纸底色」= 空白；剩下的最大连通块 = 地图区。
- **水面也算可走**（湖、河、海都是能移动的区域），所以地图区 = **陆地 40.03 + 水面 8.10 = 48.12 km²**，野地 P 把水面一起分完。
- 地图外 **38.19 km²** 不进任何 P，只做远景；页面上打斜线标注「地图外 · 官方地图上没有画面 · 不可走 · 只做远景」。

## 2. 三层边界：P / T / O

每个场景从里到外三层：

| 层 | 是什么 | 能不能走 | 里面放什么 |
|---|---|---|---|
| **① 能走范围 P** | 据点：建成区 + 外扩边距的**外切矩形**，裁进自己的场景方框；野地：**横平竖直的等面积矩形**（地图区外接框 4 行 5/4/4/4） | ✅ 能走 | 高清建筑、碰撞、寻路、NPC、交互 |
| **② 缓冲带 B** | 场景地面 T 里、P 之外的部分 | ⚠️ 物理上能走，但不是玩法区 | 30–60 m 自然屏障（密林/岩壁/水/围墙）+ 低模外围 |
| **③ 远景环 R** | 从 T 的边缘往外到外框 O | ❌ 不能走、不碰撞、无寻路 | 同源低精度地形 + blend 里现成的 `C_lod_远景碎片` |

```
远景外框 O（不可走、不碰撞）：低精度地形 + 建筑/地标剪影，一直铺到雾里
└─ 场景地面 T（引擎硬边界，走不出这个方框）
   └─ 缓冲带 B（低模、可走但不该去）
      └─ 能走范围 P：高清建筑 / 碰撞 / 寻路 / NPC
```

**一句话**：**P 才是能走的地方；T 只是地形要做多大；O 只是背景。**

## 3. 硬规则与自检

**规则（2026-11-03 用户裁定，改方案也不能破）**

1. **据点 P 各自不重叠**（每个是外切矩形）；据点有自己的地图，从大地图点它进的是它自己的场景。

3. **据点 P ∪ 野地 P = 整张有效地图**；野地 ∩ 据点是**设计内的重叠**（据点优先），不再要求两两不重叠。自检要求：覆盖无缺口、野地两两不重叠、据点两两不重叠。
4. **场景地面 T 和远景 O 可以重叠**（不同 Mission，玩家一次只进一张）；只有 P 不能重叠。

## 6. 坐标 → 场景（玩家怎么被放进哪张图）

```
点据点 / 大地图扎营 / 开战，拿到世界坐标 (x, y)
  ↓
1. 落在某个据点 P 里？
   ├─ 是 → 进该据点场景：场景内坐标 = (x − 据点中心x, y − 据点中心y)
   └─ 否 → 继续
2. 落在某个野地 P 里？
   ├─ 是 → 进该野地场景：场景内坐标 = (x − 野地中心x, y − 野地中心y)
   └─ 否 → 水面 / 地图外，不可走，不进场景
```

**在野地场景里走进据点**：野地 P 包含据点范围，所以玩家在野地场景里会走到据点那一块。走到据点 P 的边界 →
屏幕上弹「是否进入 XX」→ 是则切到据点自己的场景（落点按真实坐标换算）；否则停在边界，继续在野地里。

**要点**

- 所有场景的 **Y+ 朝北**，1 单位 = 1 m（2026-10-26 实机确认）。
- **两张野地场景之间不直接连通**：走到场景边缘 = 回大地图；要换区域就回大地图再扎营。
- **据点 ↔ 野地**：从城门出去 → 用城门外坐标落在哪个野地 P 决定进哪张野地；反过来走到据点 P 边界 → 进据点场景。
- **据点 P 是唯一的进入判据**，不是 T。站在缓冲带 B 里不会触发切场景。

## 8. 远景环怎么用 blend 里现成的“远景碎片”

**不用自己从 `bldg/struct/veh` 重新裁、也不用重新减面。** 每个 region blend 里已经分好了 `C_lod_远景碎片` 集合（对象自定义属性 `cls='远景碎片'`、`cls_key='lod'`、`tile='wild2000_XX_YY'`），直接拿它当远景环主体。

**实测（`wild2000_05_02`，圣丹尼斯所在块）**：24,763 个对象里 `C_lod_远景碎片` 203 个 / 14.2 万面 / 76 材质；19 号块（`wild2000_04_02`）是 512 个 / 36.4 万面。**每块的量差别很大，按实际相交的块算，不要外推。**

| 集合 | 是什么 | 远景环怎么用 |
|---|---|---|
| `C_lod_远景碎片` | 建筑/道具/铁路的现成低模替身 | ✅ 直接用；近环不再减面，远环按距离剔除 |
| `C_terrain_cell_地形块` | 地形本身的网格 | ❌ 不用；远景地形从解包高度图重新采样，接缝才对得上 |
| `C_terrain_lod_地形远景块` | 地形自己的超低级替身 | 有就用它做远环地形；没有就用高度图降采样 |
| `C_veg_植被` | 植被 | 可选；billboard 或直接烘进地形色 |

**做法**

1. 以场景中心为中心，取半径 R 的方形范围；
2. 找出相交的 region 块，取每块的 `C_lod_远景碎片`；
3. 排除 P 以内的对象（P 内是高清建筑，不能和低模替身叠在一起）；
4. 按材质合并/分批，**不需要再减面**；
5. 近环（距场景边 <1.5 km）用全量；远环（>1.5 km）按距离剔除或再减面 50%；
6. 输出静态网格挂 prefab；**不碰撞、不寻路、不投影**。

**坐标系注意**：region blend 是独立块场景，原点在块中心；`C_lod` 的对象原点是 `(0,0,0)`、顶点是块局部坐标。导出到场景时要**加回块的世界中心，再减场景中心**。

**预算修正**：按块实测 14–36 万面。圣丹尼斯外框 3,936 / T 1,536 → 环 13.1 km² ≈ 3–4 块 → 42–144 万面；野地 3,072 外框 5,072 → 环 1,330 万 m² ≈ 3.3 块 → 46–119 万面。目标 **≤80 万面**：近环全量，远环减面 50% 或只留地标。

**验收**：站在场景地形边缘朝外看，画面里是连续地形 + 建筑/铁路/船剪影，一直铺到雾里；关掉远景环是明显的“地形到此为止”。

## 13. 手工调整：页面上的「编辑模式」

**入口**：`docs/世界与地编/regions_viewer.html`（双击用 Chrome 打开）→ 左上角点「**编辑模式：关**」→ 变成「开」。

> 同一个页面：不开编辑 = 只读汇报页；开了编辑 = 图形编辑器。**没有第二个页面。**

| 能改什么 | 怎么改 |
|---|---|
| 据点的**可行走范围** | 点选据点 → 方框出现 8 个把手 → 拖角/边改大小；中间圆点整体挪 |
| 据点的**场景地面 T / 远景环宽 W** | 左侧面板直接改数字，O = T + 2W 自动算 |
| 野地的**分界（矩形）** | 切「野地」→ 点选一片 → **拖 8 个把手改矩形**、中间圆点整体挪；「按外接矩形」把现有形状一键变成外接矩形 |
| 野地的**分界（多边形）** | 同上，但沿用原来的多边形顶点（拖顶点改） |
| **新建野地** | 编辑模式 → 左上角「**＋新建野地**」→ 在视野中心生成一块 2,000 × 1,500 的矩形，自动选中，拖边调整 |
| **删除野地** | 选中野地 → 「**删除这个野地**」；总数会立刻跟着变（卡片和页签同步） |

编辑模式下还可以：**滚轮缩放、空白处拖动平移**、放大/缩小按钮。

**对齐（2026-11-03 新增）**

- **吸附**：拖据点边/角时，离别的据点边、自己场景 T 的边 **30 m 内自动咬住**（画面上出橙色虚线提示）；拖野地顶点时，离别的野地顶点、据点矩形角点 30 m 内也咬住。工具栏「吸附：开/关」可切。
- **一键贴合邻居**：点「**贴合邻居**」→ 把所有相距 **60 m 内**的据点边直接对成同一条线（每对边取中线），画歪的也能一次对齐成严丝合缝。改完记得导出。

**野地也可以画成矩形**（2026-11-03 新增）

- 野地选中后：「**重画矩形**」在地图上拖一个矩形；「**按外接矩形**」把当前形状一键变成它自己的外接矩形。之后拖 8 个把手就能改。
- 工具栏「**野地全转矩形**」：一次把 17 个野地切成**等面积的矩形**（从北到南 4 行 5/4/4/4，行高按块数分配），**铺满整个地图框、重叠 0、空缝 0**；之后拖边微调（会吸附邻居）。
- 矩形超出场景地面 T 时，面板会用红字提示「形状需要 T ≥ …」；导出后脚本会**自动把 T 放到装得下**（取你的 T 和需要的 T 的较大值）。
- 矩形之间**允许重叠**（矩形不可能既铺满不规则地图又互不重叠）：脚本会报告重叠面积，但不再判失败；判定按「离哪个野地中心近」。
- 超出地图区（官方地图空白处）的部分会被裁掉——那部分本来就不能走。

**改动怎么保存**（2026-11-03 补）：

- 每改一次（拖完、改完数字）**自动存到浏览器本地**（localStorage），刷新 / 关标签页都不丢；下次打开自动恢复，顶部徽标显示「改动 N 项（未导出）」。
- 有未导出的改动时关页面，浏览器会弹「确认离开」。
- 「全部重置」会同时清掉本地缓存。
- 🔴 **本地保存 ≠ 生效**：页面写不了磁盘，**必须**点「导出改动」拿到 `scene_overrides.json`，放到 `_scratch/settlement_plan/` 再重跑脚本。

**改完怎么生效**：

1. 点「导出改动」→ 得到 `scene_overrides.json`（只含改过的项）；
2. 放到 `D:\BrainMaker\大镖客2解包分析\_scratch\settlement_plan\scene_overrides.json`；
3. 重跑 `build_scene_division.py` → `build_settlement_map.py`；
